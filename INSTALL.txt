The API performs backward-compatible PostgreSQL ALTER TABLE ADD COLUMN IF NOT EXISTS at startup. No tables or existing conversations are dropped. The current implementation treats folders as conversation folder names; entering a new name in “Move to / create folder” creates that folder grouping when the chat is moved there. User and admin accounts each see only their own conversations.
