# Roadmap
1. Stabilize ingestion and retrieval, test ownership boundaries, add stable IDs and metrics.
2. Add verified email, refresh/revocation strategy, PostgreSQL migrations and audited admin functions.
3. Add persistent user memory with user controls (view/delete/disable), multilingual embeddings, hybrid retrieval and reranking.
4. Add a bounded agent planner and authorized tools, web search and evidence sufficiency checks.
5. Add reviewed feedback queues, benchmark datasets, evaluation runs and optional LoRA/QLoRA experiments.
6. Add production CI/CD, image scanning, secrets, observability, backups, rollout and rollback.
